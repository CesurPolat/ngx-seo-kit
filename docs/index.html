Why ngx-seo-kit? ​

Keep SEO configuration close to your Angular project while keeping the build deterministic and reviewable. The CLI handles static artifacts, while the optional Angular provider updates metadata as users navigate between routes.

bash
npm install --save-dev ngx-seo-kit
npx ngx-seo-kit build
